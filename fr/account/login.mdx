## Méthodes de connexion disponibles

GoTravelXpress offre plusieurs méthodes d'authentification pour s'adapter aux profils utilisateurs et aux contraintes de chaque poste de travail.offre plusieurs méthodes d'authentification pour s'adapter aux profils utilisateurs et aux contraintes de chaque poste de travail.

<Steps>
  <Step title="Identifier votre profil utilisateur">
    Déterminez si vous êtes Administrateur, Opérateur d'Agence (comptoir), Bagagiste ou Hôtesse d'embarquement. Votre profil détermine les fonctionnalités accessibles après connexion.
  </Step>
  <Step title="Choisir une méthode de connexion">
    Sélectionnez la méthode adaptée à votre situation : mot de passe classique, Google, téléphone, Facebook ou Face Login biométrique.
  </Step>
  <Step title="Saisir les informations demandées">
    Remplissez le champ identifiant (email, téléphone ou nom d'utilisateur) et le mot de passe, ou suivez le flux d'authentification du fournisseur choisi (OTP, OAuth, reconnaissance faciale).
  </Step>
  <Step title="Accéder au tableau de bord">
    Après authentification réussie, vous êtes redirigé vers l'espace de travail GoTravelXpress correspondant à votre rôle.
  </Step>
</Steps>

### Connexion par identifiant et mot de passe

C'est la méthode standard pour la plupart des utilisateurs. Trois types d'identifiants sont acceptés :

- **Email** : l'adresse email enregistrée dans GoTravelXpress
- **Téléphone** : le numéro de téléphone associé au compte, au format local ou international
- **Nom d'utilisateur** : l'identifiant unique créé lors de l'inscription

### Connexion Google

Cliquez sur le bouton **Continuer avec Google**. Une fenêtre vous invite à choisir un compte Google autorisé. Après validation du consentement, GoTravelXpress récupère votre email et vous connecte automatiquement si celui-ci est lié à un compte existant.

### Connexion Google

### Connexion par téléphone (OTP)Connexion par téléphone (OTP)

Cliquez sur le bouton **Se connecter avec le téléphone**. Saisissez votre numéro de téléphone. Un code OTP (One-Time Password) à usage unique vous est envoyé par SMS. Saisissez ce code dans l'interface pour finaliser la connexion. Cette méthode ne nécessite pas de mot de passeCliquez sur le bouton **Se connecter avec le téléphone**. Saisissez votre numéro de téléphone. Un code OTP (One-Time Password) à usage unique vous est envoyé par SMS. Saisissez ce code dans l'interface pour finaliser la connexion. Cette méthode ne nécessite pas de mot de passe.

### Connexion Facebook

Cliquez sur le bouton **Continuer avec Facebook**. Autorisez GoTravelXpress à accéder à votre adresse email publique Facebook. Si l'email correspond à un compte existant, vous êtes connecté automatiquement.

### Face Login (reconnaissance faciale)

Cette méthode est réservée aux **postes exposés**, notamment les bornes de comptoir et les postes d'embarquement.

<Card title="Face Login pour les postes exposés" icon="camera" horizontal>
  Activez la caméra du poste. Positionnez votre visage face à l'objectif. Le système biométrique compare votre visage avec l'empreinte faciale enregistrée dans votre profil utilisateur. L'authentification est immédiate sans saisie manuelle.
</Card>

Les rôles concernés incluent principalement les **Opérateurs d'Agence** (comptoir) et les **Hôtesses** (embarquement). Consultez la sécurité dans [/fr/account/security](/fr/account/security) pour en savoir plus sur la biométrie.

## Mot de passe oublié

Si vous avez oublié votre mot de passe, procédez comme suit :

<Steps>
  <Step title="Cliquer sur Mot de passe oublié">
    Depuis la page de connexion, cliquez sur le lien **Mot de passe oublié ?**
  </Step>
  <Step title="Saisir votre adresse email">
    Entrez l'adresse email associée à votre compte GoTravelXpress.
  </Step>
  <Step title="Consulter votre boîte de réception">
    Un email de réinitialisation est envoyé à cette adresse. Ouvrez-le et cliquez sur le lien sécurisé.
  </Step>
  <Step title="Définir un nouveau mot de passe">
    Choisissez un nouveau mot de passe respectant les exigences de sécurité, puis confirmez-le.
  </Step>
</Steps>

> Si vous n'avez pas reçu l'email dans les quelques minutes, vérifiez votre dossier de courriers indésirables (spam).

## Sécurité et verrouillage

GoTravelXpress applique des règles de sécurité automatiques pour protéger les comptes contre les accès non autorisés.

- **Verrouillage après échecs** : après un nombre défini de tentatives de connexion échouées consécutives, le compte est temporairement verrouillé.
- **Délai de déverrouillage** : le délai de verrouillage augmente progressivement avec les tentatives répétées.
- **Notification** : l'administrateur de l'agence et l'utilisateur concerné peuvent être alertés en cas de verrouillage.

## Langues disponibles

La page de connexion et l'interface GoTravelXpress sont disponibles en plusieurs langues. La langue peut être changée directement depuis la page de connexion via le sélecteur de langue. Cela permet aux utilisateurs multilingues d'opérer confortablement selon leur préférence.
