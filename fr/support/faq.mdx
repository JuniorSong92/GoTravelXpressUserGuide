Voici les réponses aux questions les plus fréquentes que les agences posent à propos de GoTravelXpress : méthodes de paiement, sécurité des billets, options de licence et accès API. Si vous ne trouvez pas ce que vous cherchez, contactez directement l'équipe d'assistance via la page [Contact](/fr/support/contact).

<AccordionGroup>
  <Accordion title="GoTravelXpress fonctionne-t-il en Afrique ?">
    Oui. GoTravelXpress est conçu avec les marchés africains à l'esprit. La plateforme est entièrement compatible avec les paiements **Mobile Money**, y compris MTN Mobile Money, Orange Money et Wave, ainsi qu'avec Visa/Mastercard, les virements bancaires et les espèces. Tous les flux de paiement génèrent des factures automatiques, pour que votre comptabilité reste précise quelle que soit la méthode de paiement du client.
  </Accordion>

  <Accordion title="Puis-je gérer plusieurs agences ?">
    Oui. GoTravelXpress prend en charge la **gestion multi-agences** nativement. Vous pouvez créer et configurer plusieurs sites d'agences sous un seul compte, assigner des rôles utilisateur personnalisables au personnel, et appliquer des permissions granulaires pour contrôler exactement ce que chaque utilisateur peut voir et faire.

    La prise en charge multi-agences est disponible avec les licences **Premium** et **Enterprise**. La licence Enterprise inclut en outre le marque blanc (white-label) pour que chaque agence puisse opérer sous sa propre identité.

    Consultez la page [Types de Licence](/fr/license-types) pour une comparaison complète des fonctionnalités.
  </Accordion>

  <Accordion title="Quelles méthodes de paiement sont acceptées ?">
    GoTravelXpress prend en charge les méthodes de paiement suivantes pour les transactions passagers et agences :

    - **Mobile Money** : MTN Mobile Money, Orange Money, Wave
    - **Cartes bancaires** : Visa et Mastercard
    - **Virements bancaires**
    - **Espèces**

    Chaque transaction génère automatiquement une facture, maintenant vos enregistrements financiers propres et prêts pour un audit sans aucune saisie manuelle.
  </Accordion>

  <Accordion title="Les billets sont-ils sécurisés ?">
    Oui. Chaque billet numérique émis via GoTravelXpress contient un **QR code unique, chiffré**. Le personnel d'embarquement peut vérifier le code en temps réel lors de l'enregistrement, ce qui prévient la fraude et garantit que chaque billet ne peut être utilisé qu'une seule fois. Le système signale immédiatement les tentatives de scan en double pour que votre équipage puisse réagir.
  </Accordion>

  <Accordion title="Proposez-vous une API ?">
    Oui. GoTravelXpress inclut une **API REST entièrement documentée** qui vous permet de connecter la plateforme avec vos outils existants, y compris les systèmes ERP, les logiciels de comptabilité et les applications mobiles. Vous pouvez automatiser la création de réservations, interroger les données de voyage, déclencher les flux de paiement, et plus encore.

    L'accès API est inclus dans les licences **Premium** et **Enterprise**. Reportez-vous à la section [Référence API](/fr/api/overview) pour la documentation des points de terminaison, les détails d'authentification et des exemples de code.
  </Accordion>

  <Accordion title="Quelle est la différence entre les types de licence ?">
    GoTravelXpress propose cinq niveaux de licence pour correspondre aux agences de toutes tailles :

    | Licence | Idéal pour | Points forts |
    | --- | --- | --- |
    | **Gratuite** | Évaluation | Accès de base, fonctionnalités limitées |
    | **Essai 14 jours** | Test avant achat | Toutes les fonctionnalités, limité dans le temps |
    | **Basique** | Petites agences | Modules de réservation et de paiement essentiels |
    | **Premium** | Agences en croissance | Tous les modules, y compris l'accès API REST |
    | **Enterprise** | Opérations multi-sites | Multi-agences, marque blanche, assistance prioritaire |

    Toutes les licences sont **perpétuelles** : vous payez une fois et conservez un accès complet à votre niveau pour toujours, sans frais d'abonnement récurrents.

    Consultez [Types de Licence](/fr/license-types) pour une comparaison détaillée côte à côte.
  </Accordion>

  <Accordion title="Y a-t-il des frais d'abonnement récurrents ?">
    Non. GoTravelXpress utilise un **modèle de licence perpétuelle**. Vous achetez votre licence une fois et conservez un accès complet à toutes les fonctionnalités incluses dans ce niveau, pour toujours. Il n'y a pas de frais de renouvellement mensuels ou annuels, ni de frais cachés.

    <Tip>
      Si votre agence se développe et que vous avez besoin de plus de fonctionnalités, vous pouvez passer à un niveau de licence supérieur à tout moment en contactant l'équipe d'assistance.
    </Tip>
  </Accordion>

  <Accordion title="Comment mes données sont-elles protégées ?">
    GoTravelXpress prend la sécurité des données au sérieux. Les données de votre agence sont protégées par :

    - Un **chiffrement 256 bits** pour les données au repos et en transit
    - Des pratiques de traitement des données **conformes au RGPD**
    - Des **serveurs dédiés** pour que vos données ne soient jamais mélangées avec d'autres locataires

    Pour tous les détails sur la manière dont vos données sont collectées, stockées et utilisées, consultez la [Politique de Confidentialité](/fr/account/privacy-policy).
  </Accordion>
