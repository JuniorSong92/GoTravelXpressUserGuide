## Comment utiliser ce guide

<Steps>
  <Step title="Choisissez votre rôle">
    Cliquez sur la carte correspondant à votre profil dans le système.
  </Step>
  <Step title="Suivez le parcours pas à pas">
    Chaque page présente les écrans dans l'ordre chronologique d'utilisation.
  </Step>
  <Step title="Comparez avec votre écran">
    Les captures montrent exactement ce que vous devez voir. Si votre écran diffère, contactez votre Admin.
  </Step>
</Steps>

<Note>
  Ce guide est complémentaire à la [Documentation technique](/fr/introduction). Pour la référence complète des fonctionnalités, consultez les modules détaillés.
</Note>
