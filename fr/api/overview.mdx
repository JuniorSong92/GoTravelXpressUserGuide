Cette page présente l'API REST/JSON de GoTravelXpress incluse dans le Plan Pro d'Eagle Tech.Cette page présente l'API REST/JSON de GoTravelXpress réservée à la licence Plan Pro d'Eagle Tech. Elle vous permet d'intégrer les opérations de transport (ventes, bagages, embarquement) directement dans vos systèmes métier. Avant de passer vos premiers appels, vous devez disposer d'une licence active et d'une clé API. Le contrat d'accès exact est disponible sur demande.

## Points de terminaison

L'API est exposée sous la forme suivante :

```text
https://gotravelxpress.wuaze.com/api/v1
```

> Cette URL d'exemple est à confirmer avec l'équipe GoTravelXpress.

Toutes les requêtes et réponses utilisent le format JSON et l'encodage UTF-8.

## Codes HTTP

L'API renvoie des codes HTTP standards.

| Code | Signification | Cas courant |
| :-- | :-- | :-- |
| 200 | OK | Requête réussie et réponse présente. |
| 201 | Created | Ressource créée avec succès. |
| 400 | Bad Request | Paramètres manquants ou invalides. |
| 401 | Unauthorized | Token manquant ou invalide. |
| 403 | Forbidden | Accès refusé pour ce rôle ou cette ressource. |
| 404 | Not Found | Ressource introuvable. |
| 409 | Conflict | Conflit métier (doublon, état incompatible). |
| 429 | Too Many Requests | Limite de débit dépassée. |
| 500 | Internal Server Error | Erreur interne du serveur. |

## Pagination

Les listes paginées acceptent deux paramètres de requête :

| Paramètre | Type | Défaut | Description |
| :-- | :-- | :-- | :-- |
| `page` | entier | `1` | Numéro de la page demandée. |
| `limit` | entier | `20` | Nombre d'éléments par page. |

La réponse paginée type inclut un objet `meta` :

```json
{
  "data": [],
  "meta": {
    "page": 1,
    "limit": 20,
    "total": 0,
    "total_pages": 0
  }
}
```

## Rate limiting

Un rate limiting est en place sur les points de terminaison de l'API. Les détails exacts (nombre de requêtes par minute et stratégie de fenêtre) sont à confirmer avec l'équipe GoTravelXpress.
