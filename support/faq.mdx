Here are answers to the most common questions agencies ask about GoTravelXpress — covering everything from payment methods and ticket security to licensing options and API access. If you don't find what you're looking for, reach out to the support team directly via the [Contact page](/support/contact).

<AccordionGroup>

  <Accordion title="Does GoTravelXpress work in Africa?">
    Yes. GoTravelXpress is built with African markets in mind. The platform is fully compatible with **Mobile Money** payments — including MTN Mobile Money, Orange Money, and Wave — alongside Visa/Mastercard, bank transfers, and cash. All payment flows generate automatic invoices, so your accounting stays accurate regardless of how a customer pays.
  </Accordion>

  <Accordion title="Can I manage multiple agencies?">
    Yes. GoTravelXpress supports **multi-agency management** out of the box. You can create and configure multiple agency sites under a single account, assign customizable user roles to staff, and apply granular permissions to control exactly what each user can see and do.

    Multi-agency support is available on **Premium** and **Enterprise** licenses. Enterprise additionally includes white-label branding so each agency can operate under its own identity.

    See the [License Types](/license-types) page for a full feature comparison.
  </Accordion>

  <Accordion title="What payment methods are accepted?">
    GoTravelXpress supports the following payment methods for passenger and agency transactions:

    - **Mobile Money** — MTN Mobile Money, Orange Money, Wave
    - **Bank cards** — Visa and Mastercard
    - **Bank transfers**
    - **Cash**

    Every transaction automatically generates an invoice, keeping your financial records clean and audit-ready without any manual entry.
  </Accordion>

  <Accordion title="Are the tickets secure?">
    Yes. Every digital ticket issued through GoTravelXpress contains a **unique, encrypted QR code**. Boarding staff can verify the code in real time at check-in, which prevents fraud and ensures each ticket can only be used once. The system flags duplicate scan attempts immediately so your crew can act on them.
  </Accordion>

  <Accordion title="Do you offer an API?">
    Yes. GoTravelXpress includes a **fully documented REST API** that lets you connect the platform with your existing tools — including ERP systems, accounting software, and mobile applications. You can automate reservation creation, query trip data, trigger payment flows, and more.

    API access is included in the **Premium** and **Enterprise** licenses. Refer to the [API Reference](/api/overview) section for endpoint documentation, authentication details, and code examples.
  </Accordion>

  <Accordion title="What is the difference between license types?">
    GoTravelXpress offers five license tiers to match agencies of every size:

    | License | Best for | Key highlights |
    |---|---|---|
    | **Free** | Evaluation | Basic access, limited features |
    | **14-day Trial** | Testing before buying | Full-featured, time-limited |
    | **Basic** | Small agencies | Core reservation and payment modules |
    | **Premium** | Growing agencies | All modules, including REST API access |
    | **Enterprise** | Multi-site operations | Multi-agency, white-label, priority support |

    All licenses are **perpetual** — you pay once and keep full access to your tier forever, with no recurring subscription fees.

    See [License Types](/license-types) for a detailed side-by-side comparison.
  </Accordion>

  <Accordion title="Is there a recurring subscription fee?">
    No. GoTravelXpress uses a **perpetual license model**. You purchase your license once and retain full access to all features included in that tier — forever. There are no monthly or annual renewal fees, and no hidden charges.

    <Tip>
      If your agency grows and you need more features, you can upgrade to a higher license tier at any time by contacting the support team.
    </Tip>
  </Accordion>
