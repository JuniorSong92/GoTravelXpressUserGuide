This page introduces the GoTravelXpress REST/JSON API, available to Eagle Tech Pro Plan customers. It lets you integrate transport operations such as ticket sales, baggage handling, and boarding directly into your business systems. Before making your first calls, you need an active license and an API key. The exact access contract is available on request.

## Base URL

The API is available at the following example endpoint:

```text
https://gotravelxpress.wuaze.com/api/v1
```

> This base URL is an example and should be confirmed with the GoTravelXpress team.

All requests and responses are JSON encoded in UTF-8.

## HTTP status codes

The API returns standard HTTP status codes.

| Code | Meaning | Common scenario |
| :-- | :-- | :-- |
| 200 | OK | Request succeeded and a response body is present. |
| 201 | Created | Resource was created successfully. |
| 400 | Bad Request | Missing or invalid parameters. |
| 401 | Unauthorized | Token is missing, expired, or invalid. |
| 403 | Forbidden | Access denied for this role or resource. |
| 404 | Not Found | Requested resource does not exist. |
| 409 | Conflict | Business conflict such as a duplicate or invalid state. |
| 429 | Too Many Requests | Rate limit exceeded. |
| 500 | Internal Server Error | Unexpected server-side error. |

## Pagination

List endpoints accept two query parameters:

| Parameter | Type | Default | Description |
| :-- | :-- | :-- | :-- |
| `page` | integer | `1` | Page number to request. |
| `limit` | integer | `20` | Number of items per page. |

Paginated responses include a `meta` object:

```json
{
  "data": [],
  "meta": {
    "page": 1,
    "limit": 20,
    "total": 0,
    "total_pages": 0
  }
}
```

## Rate limiting

Rate limiting applies to API endpoints. Exact limits, such as requests per minute and window strategy, should be confirmed with the GoTravelXpress team.

<Note>
  To obtain the exact API access contract and confirm the base URL and rate limits, contact the team by email at [contact@prozigzag.com](mailto:contact@prozigzag.com).
</Note>
