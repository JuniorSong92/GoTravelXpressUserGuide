## Preguntas frecuentes

Preguntas frecuentes sobre nuestra plataforma

¿Funciona el SaaS en África?

Sí, nuestra solución es totalmente compatible con pagos Mobile Money (MTN Mobile Money, Orange Money, Wave, etc.) y adaptada a las especificidades del mercado africano.

¿Puedo gestionar varias agencias?

¡Absolutamente! Nuestra plataforma admite la gestión multi-agencia con roles de usuario personalizables y permisos granulares para cada sitio.

¿Qué métodos de pago se aceptan?

Aceptamos Mobile Money, tarjetas bancarias Visa/Mastercard, transferencias bancarias y pagos en efectivo con generación automática de facturas.

¿Los billetes son seguros?

Sí, todos nuestros billetes digitales incluyen un código QR único y cifrado, verificable en tiempo real para evitar fraudes y duplicados.

¿Ofrecen una API?

Sí, ofrecemos una API REST completamente documentada para integrar nuestra solución con tus otros sistemas (ERP, contabilidad, aplicaciones móviles).
