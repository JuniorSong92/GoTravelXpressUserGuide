Частые вопросы

## Частые вопросы

Часто задаваемые вопросы о нашей платформе

Работает ли SaaS в Африке?

Да, наше решение полностью совместимо с платежами Mobile Money (MTN Mobile Money, Orange Money, Wave и др.) и адаптировано к особенностям африканского рынка.

Могу ли я управлять несколькими агентствами?

Абсолютно! Наша платформа поддерживает управление несколькими агентствами с настраиваемыми ролями пользователей и детальными разрешениями для каждого сайта.

Какие способы оплаты принимаются?

Мы принимаем Mobile Money, банковские карты Visa/Mastercard, банковские переводы и наличные платежи с автоматической генерацией счетов.

Билеты безопасны?

Да, все наши цифровые билеты содержат уникальный зашифрованный QR-код, проверяемый в реальном времени для предотвращения мошенничества и дубликатов.

Предлагаете ли вы API?

Да, мы предлагаем полностью документированный REST API для интеграции нашего решения с вашими другими системами (ERP, бухгалтерия, мобильные приложения).
