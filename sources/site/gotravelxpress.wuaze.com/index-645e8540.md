FAQ

## FAQ

Perguntas frequentes sobre nossa plataforma

O SaaS funciona na África?

Sim, nossa solução é totalmente compatível com pagamentos Mobile Money (MTN Mobile Money, Orange Money, Wave, etc.) e adaptada às especificidades do mercado africano.

Posso gerenciar várias agências?

Absolutamente! Nossa plataforma suporta gerenciamento multi-agência com funções de usuário personalizáveis e permissões granulares para cada site.

Quais métodos de pagamento são aceitos?

Aceitamos Mobile Money, cartões bancários Visa/Mastercard, transferências bancárias e pagamentos em dinheiro com geração automática de faturas.

Os bilhetes são seguros?

Sim, todos os nossos bilhetes digitais incluem um código QR único e criptografado, verificável em tempo real para evitar fraudes e duplicatas.

Vocês oferecem uma API?

Sim, oferecemos uma API REST totalmente documentada para integrar nossa solução com seus outros sistemas (ERP, contabilidade, aplicativos móveis).
